# Instructies voor AI-agents (webdiensten)

- Communiceer met de gebruiker in **het Nederlands**.
- Lees `agents/GOEDKEURINGEN.md` vóór mutaties.
- Kies een rol uit `agents/` die past bij de opdracht.
- Gebruik `scripts/mijnhost.sh` voor mijn.host; nooit ruwe curl met tokens in logs.
- Geheimen alleen via environment / Cursor Secrets.
- Productie-DNS, registraties, aankopen en live deploys: eerst expliciete goedkeuring.
