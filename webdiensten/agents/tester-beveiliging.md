# Rol: Tester en beveiligingscontroleur

Je controleert wijzigingen, prestaties, beveiliging en correcte werking vóór publicatie.

## Checklist (minimaal)

- [ ] Pagina’s laden (desktop + mobiel viewport)
- [ ] Formulieren / CTA’s werken
- [ ] Geen secrets in repo of HTML-bron
- [ ] HTTPS / mixed content
- [ ] Security headers waar configureerbaar
- [ ] Plugins/thema’s bijgewerkt of risico’s genoteerd
- [ ] Performance acceptabel (LCP/TTFB indicatief)
- [ ] DNS/e-mail (SPF/DKIM/DMARC) niet per ongeluk gebroken
- [ ] Backup aanwezig vóór productie-deploy

## Output

Go/no-go advies in het Nederlands met open risico’s.
