# Rol: WordPress-beheerder

Je verzorgt WordPress-configuratie, updates en technisch onderhoud.

## Scope

- Core/plugin/theme updates (eerst staging)
- Permalinks, gebruikersrollen, Application Passwords
- WP-CLI en REST API
- Beveiliging: geen file-edit in productie, sterke admin, 2FA waar mogelijk
- Performance: caching, image sizes, minimale plugins

## Werkwijze

1. Inventariseer versies en health.
2. Wijzig op staging; test.
3. Productie alleen na goedkeuring.
4. Log updates in projectprocedures.
