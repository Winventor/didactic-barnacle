# Agentrollen

Gebruik deze bestanden als vaste instructies bij Cloud Agents of Task-subagents. Bij een Nederlandse opdracht: kies de passende rol(len), lees het rolbestand, en respecteer de goedkeuringsgrenzen in `GOEDKEURINGEN.md`.

| Rol | Bestand | Typische NL-opdrachten |
|-----|---------|------------------------|
| Websiteontwikkelaar | `websiteontwikkelaar.md` | “Pas de homepage aan”, “maak een dienstenpagina” |
| Hostingbeheerder | `hostingbeheerder.md` | “Bereid hosting voor”, “installeer WordPress” |
| Domein- en DNS-beheerder | `domein-dns-beheerder.md` | “Is dit domein vrij?”, “toon mijn DNS” |
| WordPress-beheerder | `wordpress-beheerder.md` | “Update plugins op staging”, “maak een Application Password” |
| Tester en beveiligingscontroleur | `tester-beveiliging.md` | “Controleer of de site veilig live kan” |
