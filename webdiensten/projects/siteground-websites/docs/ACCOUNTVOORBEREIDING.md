# Accountvoorbereiding SiteGround

## Stappen (jij voert checkout uit)

1. Ga naar https://eu.siteground.com/web-hosting.htm  
2. Kies **GrowBig** (of GoGeek) — datacenter bij voorkeur **Nederland**  
3. Domein: tijdelijk of bestaand  
4. Accountgegevens + betaling  
5. Bevestig aan de agent dat het account live is  

## Daarna (agent)

1. SSH-key genereren of public key aanleveren via Secret-flow  
2. Eerste site uit `templates/wordpress-basis`  
3. Staging-workflow documenteren per site  
4. Onderhoudsprocedures activeren  

**Geen betaald account wordt door de agent afgesloten.**
