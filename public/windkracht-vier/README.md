## Foto’s vanaf iOS

Chat-attachments in de Cursor-app zijn alleen visuele context. Voor bestanden in de collage:

1. Upload via GitHub naar [`fotos/`](fotos/):  
   https://github.com/Winventor/didactic-barnacle/upload/master/public/windkracht-vier/fotos
2. Zeg in Cursor dat de foto’s klaarstaan, zodat de collage (`src/lib/windkracht-vier/photos.ts`) wordt bijgewerkt.

Zie [`fotos/README.md`](fotos/README.md) voor het volledige stappenplan.
