# Foto’s Windkracht Vier

Plaats hier de **echte** bootfoto’s (jpg/png/webp). De huidige `wk4-*.jpg`-bestanden zijn tijdelijke sfeerbeelden en mogen worden verwijderd of overschreven.

## Upload vanaf iPhone (aanbevolen)

Foto’s in de Cursor iOS-chat worden **niet** als bestanden in de repo opgeslagen. Upload ze via GitHub:

1. Open deze link op je iPhone (Safari of GitHub-app):  
   https://github.com/Winventor/didactic-barnacle/upload/master/public/windkracht-vier/fotos
2. Kies je foto’s uit de Fotobibliotheek (meerdere tegelijk mag).
3. Commit naar `master` (bijv. bericht: `Add Windkracht Vier foto’s`).
4. Stuur in Cursor:  
   **De foto’s staan in public/windkracht-vier/fotos — vervang de sfeerbeelden en werk de collage bij.**

Daarna werkt de agent `src/lib/windkracht-vier/photos.ts` bij en deployt opnieuw naar GitHub Pages.

## Alternatieven

- **Desktop:** sleep foto’s naar deze map, `git add` / `commit` / `push`.
- **Downloadlinks:** plak publieke URL’s (Drive/Dropbox direct) in de Cursor-chat en vraag de agent ze hier op te slaan.
